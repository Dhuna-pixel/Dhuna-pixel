## 🧪 Current experiments

### 🕸️ [MeshLink](https://github.com/Dhuna-pixel/MeshLink) — **first spell**
An Android prototype for multi-hop device-to-device messaging. Messages can travel across nearby devices, with forwarding, route history, and a three-node simulation.

`Kotlin` · `Jetpack Compose` · `Android`

### 🌾 [RuralLens](https://github.com/Dhuna-pixel/RuralLens) — **second spell**
A portfolio monitoring demo for rural lending teams: explore portfolio health, spot emerging risks, investigate accounts, and coordinate interventions.

*Runs locally with synthetic data; live database integration is still being verified.*
